MONSTER RUNNER - playtest build (Windows 64-bit)

How to play
  1. Unzip the whole folder anywhere (do not run it from inside the zip).
  2. Double-click MonsterRunner.exe.

Controls
  A / D or Left / Right   change lane
  W / Up / Space          jump
  S / Down                fast fall
  Esc or P                pause
  Gamepad: D-pad + A, Start to pause

Notes
  - No install needed. If Windows SmartScreen warns about an unknown publisher, choose More info > Run anyway.
  - Progress is stored per user (Windows registry). F12 on the menu resets it, F11 unlocks all levels.
  - Feedback welcome: which level felt too hard or too easy, anything that looked or ran badly, and your PC specs.
